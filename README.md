# Lab 1 – Development Environment Setup & Git Fundamentals

Sample project skeleton used to practise init, commit, branch, merge, conflict resolution.
Build with Maven: `mvn test` (requires Java 17+).

## Greeter API
- `Greeter.greet(name)` – returns a greeting.
- `Greeter.farewell(name)` – returns a goodbye message.
